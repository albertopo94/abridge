# Google AI Studio Upstream (`aistudio/*`)

Integrate Google AI Studio's Interactions API as a fifth model provider in Abridge (`aistudio/*`), keeping tools, workspaces, and agent loops inside local client agents.

## Specs

- **S1 (user intent)**: Integrate Google AI Studio direct model inference (`model="..."`, never `agent="antigravity-preview-09-2026"` / remote sandbox) into Abridge, supporting `aistudio/gemini-4-hydrogen`, `aistudio/gemini-3.8-flash`, and `aistudio/gemini-4-argon` with `[AI Studio]` display tags and `--provider aistudio` defaulting to `aistudio/gemini-4-hydrogen` (Checkpoints 001–016 + user decision: "Los 3 con Hydrogen por defecto").
- **S2 (effort tiers & presets)**: Accept both base IDs (`aistudio/gemini-4-hydrogen` -> `high`, `aistudio/gemini-3.8-flash` -> `medium`, `aistudio/gemini-4-argon` -> `high`) and Antigravity-style tier-suffixed model IDs (`-xhigh`, `-high`, `-medium`, `-low`), validating `generation_config.thinking_level` strictly per model (`gemini-4-hydrogen`: `low|medium|high|xhigh`; `gemini-3.8-flash` & `gemini-4-argon`: `low|medium|high`; reject `minimal`/`thinking_budget` on Hydrogen and `xhigh` on Flash with HTTP 400). Expose effort-suffixed entries in client presets just like Antigravity CLI (user decision: "Como lo hace actualmente para los modelos de antigravity cli").
- **S3 (independent Keychain credential & CLI)**: Store the Gemini API key in a dedicated macOS Keychain generic-password item (`service="abridge-aistudio"`, `account="api-key"`), completely isolated from Antigravity OAuth (`gemini/antigravity`) and `~/.abridge/api_key`. Manage via `abridge auth aistudio` (`set`, `status`, `remove`), requesting secrets interactively with hidden echo (`getpass` / `/usr/bin/security` without exposing secrets in `argv`, shell history, config files, or logs), with defensive secret redaction and independent degraded startup (Checkpoints 004, 013 + user decision: "abridge auth aistudio").
- **S4 (stateless Interactions API & SSE Step Assembler)**: Call `POST https://generativelanguage.googleapis.com/v1beta/interactions` with `x-goog-api-key` and `store=false` always (no `previous_interaction_id` sent to Google, no silent `store=true` fallback). Parse `step.start`, `step.delta` (`text`, `arguments_delta`, `thought_signature`, `thought_summary`), `step.stop`, `interaction.completed`, and `interaction.requires_action`, emitting normalized `StreamEvent` objects while preserving unmodified raw Google `steps[]` JSON for exact replay. Record TTFB, first-delta, and inter-event gap timings (Checkpoints 007, 010, 011, 015, 016).
- **S5 (InteractionStepCache & protocol compatibility)**: Translate `/v1/chat/completions`, `/v1/messages`, and `/v1/responses` inputs (messages, `system_instruction`, `tools`, `tool_choice`, parallel `function_call` / `function_result`, Anthropic `is_error`, and explicit HTTP 400 rejection of unsupported non-text/multimodal/remote-tool payloads). Maintain RAM-only `InteractionStepCache` with TTL, LRU capacity limits, per-session locking, `public_call_id <-> native_call_id` mapping, ephemeral `abridge_response_id -> state` mapping for `previous_response_id` (plus full `input` replay), `x-abridge-session-id` header + deterministic SHA-256 prefix fallback with ambiguity detection, idempotency on retries/duplicates, and explicit HTTP `409 Conflict` (`interaction_state_missing`) on expired/lost/ambiguous state (never inventing `DUMMY_THOUGHT_SIGNATURE`) (Checkpoints 010, 011, 012, 016).
- **S6 (routing, dashboard, setup & regression)**: Exclude `aistudio/` (and `junie/`) from `is_antigravity_model()` and dispatch `is_aistudio_model()` before `_guard_antigravity()` in all 3 endpoints (`/v1/chat/completions`, `/v1/messages`, `/v1/responses`), `/v1/models`, and `/api/aistudio/status`. Add an AI Studio availability tab in the left dashboard column (no fake quota bars, no secret values) and an `AI Studio` provider tab on client cards. Wire `--provider aistudio` into client configurators and CLI. Zero regression to Antigravity OAuth, Cursor, OpenCode, Junie, or `~/.abridge/api_key`.
